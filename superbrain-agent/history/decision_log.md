## BIO-001 | 掌静脉识别 | 裁决：延迟

| 字段 | 内容 |
|------|------|
| **提案ID** | BIO-001 |
| **提案内容** | 将掌静脉识别技术导入 eufy 主系列智能门锁，作为旗舰卖点 |
| **裁决** | ❌ 延迟（不进主系列，保留旗舰Pro候选池） |
| **裁决日期** | 2026-07 |
| **核心理由** | 营销宣传价值 > 用户可感知价值；BOM增加$35+ 压缩利润；GDPR合规成本未消化 |
| **反对条件** | 用户额外价值感知不足、成本过高、海外合规风险高 |
| **重新评估条件** | ① 模组及整机BOM下降≥30% ② 批量可靠性测试通过 ③ 隐私处理链路明确 ④ 用户对特殊环境（雨天/手指潮湿）价值形成稳定认知 |
| **决策模式标签** | `高技术感知≠高用户价值` `合规成本前置` `旗舰而非主系列` |
| **潜在盲区** | 可能因早期差评低估技术迭代速度；若竞品12个月内普及，将失去高端差异化窗口 |

## BIO-002 | UWB 免持解锁 | 裁决：否决

| 字段 | 内容 |
|------|------|
| **提案ID** | BIO-002 |
| **提案内容** | 效仿 Schlage Sense Pro，为 eufy 旗舰系列增加 UWB 免持解锁功能 |
| **裁决** | ❌ 否决（暂不投入，保留技术监测） |
| **裁决日期** | 2026-07 |
| **核心理由** | 生态就绪度不足（仅高端手机支持UWB）；安全信任未建立（"靠近自动开门"心理门槛高）；eufy 不应为竞品承担市场教育成本 |
| **反对条件** | UWB手机渗透率<30%、用户安全顾虑未解决、Schlage市场表现不佳 |
| **重新评估条件** | ① Apple/Google UWB数字钥匙生态成熟 ② 用户对无感解锁安全信任建立（可参考竞品NPS数据） ③ eufy自身App体验能承载复杂UWB配置流程 |
| **决策模式标签** | `生态就绪度>技术就绪度` `不为竞品做市场教育` `安全心理门槛` |
| **潜在盲区** | 如果Apple在iOS 20中力推UWB Home Key作为标准，窗口期可能突然打开 |

## BIO-003 | 8节AA电池→充电锂电池切换 | 裁决：有条件通过

| 字段 | 内容 |
|------|------|
| **提案ID** | BIO-003 |
| **提案内容** | 将 C30/C33 的 8节AA电池方案改为内置可充电锂电池 |
| **裁决** | ✅ 有条件通过（C30 Pro 项目启动） |
| **裁决日期** | 2026-07 |
| **核心理由** | 用户强需求（C30每月换电池为最大投诉点）；竞品已普遍采用锂电池；技术成熟；属于存量优化而非新方向 |
| **反对条件** | 充电电池增加BOM成本$8-12，需确认ASP能否支撑 |
| **重新评估条件** | 无需重评，已进入开发 |
| **决策模式标签** | `用户强需求驱动` `存量体验优化` `跟随而非领先` |
| **潜在盲区** | 充电电池本身也需要2-3年更换，长期可靠性数据缺失 |

## 新提案相似性检查规则

当生成新候选方案时，必须逐一检查是否命中上述裁决记录：

1. **关键词匹配**：提案内容是否包含"掌静脉/静脉识别/生物特征"、"UWB/超宽带/免持解锁"等已被否决的技术方向
2. **决策模式匹配**：新提案的方向逻辑是否命中 `高技术感知≠高用户价值` 或 `生态就绪度>技术就绪度` 等已沉淀模式
3. **如果命中**：必须在输出中明确标注 —— "⚠️ 历史相似警告：该方向与 [提案ID] 的 [裁决类型] 相似，反对理由是 [核心理由]。如仍想推进，需证明 [重新评估条件] 已满足。"
4. **如果未命中但疑似相似**：标注 "ℹ️ 该方向与 [提案ID] 存在部分重叠，建议在 Court 评审阶段主动引用相关裁决记录。"
