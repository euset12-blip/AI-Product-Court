# AI Product Court · 基于多智能体的产品决策评审系统

## 项目背景

针对消费电子企业产品定义环节「洞察规模受限、经验依赖个人、试错成本高昂」的痛点，设计一套 AI 原生的产品仿真评审体系，用多智能体对立辩论 + 反事实推演 + 决策记忆沉淀的机制，实现低成本、系统性的方案反向淘汰。

本项目为 **2026 AI 先锋未来人才大赛安克创新赛道**参赛作品，以 eufy 智能门锁为验证场景，输出完整可落地的企业级产品决策 SOP。

## 核心设计

- **反向淘汰机制**：核心不是生成创意，而是系统性排除低价值方向，降低产品试错成本
- **多智能体 Runtime**：7 个独立目标 Agent 并行评审，冲突自动提炼，支持反事实多路径推演
- **决策记忆体系**：四层结构的 Product Brain，沉淀决策边界条件，实现组织经验可复用、可进化
- **飞书原生落地**：零前端开发，基于飞书文档、多维表格、智能伙伴、自动化能力即可快速部署

## 已验证的技术实现

本项目区分「设计蓝图」和「已实际开发验证的部分」：

- **完整方法论设计与飞书落地方案**：`01-04` 号 md 文档和 `docx` 文件，代表设计层面的完整思考——从开题报告、方法论设计、飞书原生落地方案到产品案例演示。
- **核心环节的真实代码验证**：位于 [`superbrain-agent/`](./superbrain-agent/README.md) 目录，是这套方法论中「超级智囊」和「评审矩阵」两个核心环节的最小可运行实现。

`superbrain-agent/` 已验证的能力（详见其 README）：
- **超级智囊 Agent**（79 个测试通过）：基于竞品/差评/案例三类知识源生成有证据支撑的候选方案，含历史裁决相似性检查
- **评审矩阵**（6 方 Agent）：3 个行业专家 + 3 个用户替身对每个候选独立评审，投票判定 + 历史联动
- **可复现性验证**：同一知识源跑 5 轮统计方向分布，验证推理稳定性
- **对抗性测试**：修改知识源方向后重新生成，验证 AI 推理对证据的真实依赖性

最有说服力的发现：我们通过对照实验发现评审矩阵存在证据池共享问题（67% 证据重叠）并完成修复，通过对抗性测试验证了 AI 推理对知识源的真实依赖性，同时也如实记录了测试中发现的模型结构性偏好等局限。完整验证报告见 `superbrain-agent/output/` 目录。

## 系统架构速览

```
产品想法输入 → Idea Normalizer → Evidence Retrieval → Agent Debate Round
                                                           ↓
                                              Counterfactual Simulation
                                                           ↓
                                                   Conflict Resolver
                                                           ↓
                                                   Human Arbitration
                                                           ↓
                                                    Decision Memory
                                                           ↓
                                              Product Brain（四层）
                                              ├─ Decision Records
                                              ├─ Decision Patterns
                                              ├─ Boundary Conditions
                                              └─ Challenger Memory
```

## 项目价值

- AI 原生的多方并行评审相比传统跨部门串行沟通，具备缩短评审周期、提升方案验证效率的潜力（具体收益取决于实际落地场景，当前 demo 阶段暂无量产环境实测数据）
- 决策经验结构化沉淀，降低人员流动带来的经验流失
- 支持跨品类复用，可平移至充电、影音、智能家居等全品类
